# إصلاحات تجربة تسجيل المستخدم — 2026-07-25

## النطاق
إصلاح مشاكل ظهرت أثناء الاختبار الميداني لدور المستخدم العادي في مسار التسجيل وإعداد الحساب.

## المشاكل المعالجة

### 1. اسم المستخدم كان يقبل فراغات أثناء الإدخال
- تم تعديل شاشة `SetupProfileScreen` بحيث:
  - تُحذف الفراغات تلقائياً أثناء الكتابة/اللصق.
  - يتم فحص القواعد محلياً أثناء الإدخال قبل استدعاء السيرفر.
  - يتم تأخير فحص التوفر 450ms لتجنب استدعاء السيرفر مع كل حرف.
  - تظهر حالة توفر اسم المستخدم داخل الحقل.

### 2. خطأ عام عند حفظ إعداد الحساب بعد Magic Link
- تم تحسين شاشة إعداد الحساب بحيث:
  - تفحص رقم الهاتف قبل الحفظ وتعرض رسالة واضحة إذا كان الرقم مستخدماً في حساب آخر.
  - تعرض رسالة أوضح عند انتهاء/عدم تطابق جلسة الرابط السحري.
- تم تعديل Edge Function `user-account` في مسار `handle_email_auth` حتى لا يعيد `user_id` مختلفاً عن JWT عند وجود بريد مربوط بحساب آخر، لأن ذلك يسبب فشل الخطوات التالية مثل `update_profile` و`register_password`.

### 3. رابط البريد السحري يصل أحياناً إلى Spam
- تم إضافة تنبيه واضح في:
  - شاشة التسجيل بالإيميل القديمة `LoginScreen`.
  - شاشة حسابي/التسجيل الموحدة `ProfileScreen`.
  - شاشة `CheckEmailScreen`.
- التنبيه يطلب من المستخدم فحص Spam / البريد غير المرغوب فيه إذا لم يصل الرابط إلى الوارد خلال دقيقة.

## مطلوب للنشر الحي
بعد رفع الكود، يجب إعادة نشر Edge Function:

```bash
supabase functions deploy user-account
```

> تحسين وصول الإيميل إلى Inbox فعلياً يحتاج إعداد دومين/SMTP مع SPF وDKIM وDMARC. التعديل الحالي يضيف تنبيه واجهة واضح للمستخدم، أما تحسين الـ deliverability فيتم من إعدادات البريد والدومين.
